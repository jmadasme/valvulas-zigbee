01 — El proyecto

Qué resuelve

Sistema de riego con válvulas Zigbee, backend propio en Docker y configuración local. La migración a Raspberry Pi está documentada. El objetivo es controlar el riego sin depender de una cuenta ni de un fabricante.

Problema

El punto de partida

Los sistemas de riego comerciales obligan a una app, una cuenta y una nube que puede desaparecer o cambiar sus condiciones.

Solución

La propuesta

Un coordinador Zigbee y un backend local que habla directo con las válvulas, con Docker para reproducir el despliegue.

01 — La idea

El agua no necesita una cuenta en la nube

Zigbee2MQTT y Mosquitto alcanzan para controlar el riego sin depender de un fabricante ni de internet.

El problema

Muchas válvulas inteligentes requieren una app del fabricante y una cuenta en la nube. Si se cae internet o el servicio, el riego queda inaccesible. Además, los datos de uso salen de la casa.

La solución

Un coordinador Zigbee local, Zigbee2MQTT en Docker y Mosquitto. Dos válvulas SONOFF SWV-NH y un interruptor ZBMINIL2 se controlan por MQTT con una CLI y un menú interactivo.
